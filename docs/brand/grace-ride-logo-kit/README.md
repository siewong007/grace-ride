# Grace Ride – logo kit (Concept A · Pilgrim Pin)

The cross's foot is pointed like a map pin (the old "cross fitchée" that pilgrims planted in the ground wherever they stopped), set inside the blue arc from the PJ State church logo.

## Colours
| Use | Hex |
|---|---|
| Grace red (cross, "Grace") | #E8462F |
| Ride blue (arc, "Ride") | #1F5DB4 |
| Church grey (新市堂, small text) | #474A4F |
| One-colour version | #2B2E33 |
| Light blue on blue backgrounds | #CFE0F7 |

## Fonts (both free on Google Fonts)
- Wordmark: **Jost**. "Grace" is Bold (700), "Ride" is Light (300).
- Chinese line: **Noto Sans SC**, Medium (500) and Bold (700).

## Files
- `svg/grace-ride-mark*.svg`: the symbol on its own (full colour, white, one colour). Pure vector shapes, no fonts needed.
- `svg/grace-ride-app-icon*.svg` and `png/…app-icon…png`: 1024 × 1024 square icons (white and blue). iOS and Android round the corners for you.
- `svg/grace-ride-logo-horizontal.svg` and `svg/grace-ride-logo-stacked.svg`: full logos with live, editable text. Install Jost, or open them in a browser while online, so the lettering shows correctly.
- `animation/grace-ride-loading-mark.svg`: the animated symbol. The cross lands, ripples spread, the arc sweeps in, then the ripples keep pulsing while the app loads.
- `animation/grace-ride-loading-screen.html`: the full loading screen. Open it in a browser and tap the logo to replay.

## Using the logo
- Keep clear space around the logo at least as wide as the cross's crossbar.
- Smallest size for the symbol is about 24 px. Below 64 px, use the app-icon drawing, which has thicker lines.
- On blue or photo backgrounds, use the white version.
